# Project Costs

This file lists the running costs of the Fallout project for transparency. It covers the whole [Fallout-build](https://github.com/Fallout-build) organisation, not any single repository.

If you'd like to help offset any of these, use the sponsor button on any Fallout repository, or see the [Sponsorship](https://github.com/Fallout-build/Fallout#sponsorship) section in the framework README.

| Position | Cost (USD) | Frequency | Notes |
|---|---|---|---|
| Domain `fallout.build` (Cloudflare Registrar) | $25.20 | Yearly | Cloudflare Registrar charges at-cost. |

Everything else the project relies on is currently free at our usage tier:

- **GitHub** (repos, issues, Actions, Packages) — free for public repositories.
- **NuGet.org** — free for OSS publishers (used once the rebrand reserves `Fallout.*` package IDs; see [#33](https://github.com/Fallout-build/Fallout/issues/33)).
- **VS Marketplace / Open VSX** — free for publishers.
- **Documentation hosting** — planned on GitHub Pages, included with the repo.

This list will grow if we ever add paid services (an organization seat tier, paid CI minutes, a dedicated docs host, etc.). Each addition will land in a PR that updates this file.
